# API Design

## Workflow

1. Inspect existing API conventions.
2. Identify consumers and compatibility risks.
3. Design request and response schemas.
4. Review authentication and authorization.
5. Describe errors and validation rules.
6. Produce test scenarios.

Read [API guidelines](references/api-guidelines.md) for compatibility and rollout decisions that affect existing callers.

## Output

- API contract
- Breaking-change assessment
- Test cases
- Unresolved decisions
